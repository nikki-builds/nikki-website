# Nikki — personal portfolio

Editorial portfolio site for a freelance web engineer. Cream, black, and yellow. Fraunces for headlines, Syne for body. One page: hero, about, skills, selected work, contact.

## Run locally

```bash
npm install
npm run dev
```

Dev server: [http://127.0.0.1:4521](http://127.0.0.1:4521)

```bash
npm run build
npm run preview
```

## Stack

- Vite + React + TypeScript
- Tailwind CSS v4
- Google Fonts: [Fraunces](https://fonts.google.com/specimen/Fraunces), [Syne](https://fonts.google.com/specimen/Syne)

## Sections

| Section | Background | Notes |
| --- | --- | --- |
| Hero | Cream `#f6f5f1` | Name + “web” highlights, yellow portrait slab |
| About / Skills | Black | Stats, three capability columns |
| Work | Cream | RecipeLens, Intake Flow, Ledger Notes |
| Contact | Yellow `#ffcb41` | `hello@nikkibuilds.dev` |

Nav underlines the section in view and flips to light type on the black band.
